## 1. Sobre o projeto

Este projeto consiste na reprodução de uma página de
login inspirada no Spotify.

O objetivo é aplicar conhecimentos de HTML, CSS,
JavaScript, acessibilidade e responsividade.

A página possui um formulário demonstrativo que não
realiza autenticação verdadeira nem envia dados.

## 2. Site de referência

Site escolhido: Spotify

Link: https://accounts.spotify.com/pt-BR/login?continue=https%3A%2F%2Fopen.spotify.com%2Fintl-pt

## 3. Checklist dos requisitos

### 1.1 — Estrutura HTML semântica e acessível

- [x] Utilização de tags semânticas.
- [x] Formulário com labels associados aos campos.
- [x] Campos com preenchimento obrigatório.
- [x] Formulário demonstrativo com JavaScript.

Foram utilizadas as tags header, main, section e footer.

Os campos possuem labels associados aos respectivos
identificadores, facilitando a acessibilidade.

O JavaScript permite simular o envio do formulário
sem transmitir ou armazenar informações.

### 1.2 — Fidelidade visual

- [x] Utilização de cores inspiradas no Spotify.
- [x] Criação de formulário centralizado.
- [x] Utilização de botão verde.
- [ ] Adicionar capturas de tela comparativas.

A interface foi desenvolvida utilizando cores
semelhantes às encontradas na página original.

Foram utilizados fundo escuro, campos de formulário
e um botão verde.

A principal diferença é que o projeto possui
uma seção acadêmica personalizada.

O formulário é demonstrativo e não reproduz
o sistema real de autenticação do Spotify.

### 1.3 — CSS

- [x] Utilização de variáveis CSS.
- [x] Utilização de diferentes seletores.
- [x] Aplicação de margin e padding.

Foram criadas variáveis para armazenar as cores
principais da página.

O projeto utiliza seletores de classe,
seletores descendentes e pseudoclasses.

O box model foi aplicado para organizar
os espaçamentos dos elementos.

### 1.4 — Responsividade

- [x] Utilização de Flexbox.
- [x] Desenvolvimento mobile first.
- [x] Utilização de media query.
- [x] Testes em diferentes tamanhos de tela.

O layout utiliza Flexbox para organizar
o formulário e as demais seções.

O CSS foi desenvolvido inicialmente para
telas pequenas.

Uma media query com min-width de 768px
ajusta o layout para telas maiores.

### 1.5 — Personalização

- [x] Criação da seção Sobre este projeto.

Foi desenvolvida uma seção personalizada
que não está presente na página original.

Ela apresenta informações sobre o trabalho
acadêmico e as tecnologias utilizadas.
